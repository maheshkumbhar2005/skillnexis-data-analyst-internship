# Skill Nexis Data Analyst Internship

## Week 1 – Excel & Data Fundamentals

This repository contains my Week 1 assignment for the Skill Nexis Data Analyst Internship.

## Project Title

Sales Performance Analysis using Excel

## Objective

The objective of this project is to analyze sales data and create meaningful summaries and visualizations using Microsoft Excel.

## Dataset

Dataset: Global Superstore 2016

The dataset contains sales-related information such as:

- Order Date
- Region
- Category
- Sub-Category
- Sales
- Quantity
- Discount
- Profit
- Customer information

## Tasks Completed

- Data cleaning and duplicate review
- Missing-value handling
- Region-wise sales analysis
- Mean, Median and Mode calculation
- Top 10 sales analysis
- Conditional formatting
- Category-wise revenue analysis
- Revenue bar chart
- Yearly sales trend
- Sales performance dashboard

## Tools Used

- Microsoft Excel
- Pivot-style analysis
- Excel formulas
- Conditional Formatting
- Charts and Dashboard

## Workbook Structure

| Sheet | Description |
|---|---|
| Week 1 Summary | Project overview |
| Cleaned Data | Prepared dataset |
| Region Sales | Region-wise sales analysis |
| Statistics | Mean, Median and Mode |
| Top 10 Sales | Highest sales transactions |
| Category Revenue | Category-wise revenue |
| Pivot Analysis | Revenue summaries |
| Sales Dashboard | Overall sales dashboard |
| Methodology | Analysis process and viva notes |
| Submission Checklist | Assignment completion checklist |

## Conclusion

The analysis provides an overview of sales performance across regions, categories and years. The dashboard and supporting analysis help identify important sales patterns and summarize the dataset effectively.

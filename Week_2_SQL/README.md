# Skill Nexis Data Analyst Internship

## Week 2 – SQL for Data Analysis

This repository contains my Week 2 assignment for the Skill Nexis Data Analyst Internship.

## Project Title

SQL for Data Analysis – Sales Data Analysis

## Objective

The objective of this project is to analyze sales data using SQL and extract meaningful insights using queries, aggregations, filtering, grouping, sorting, joins, subqueries and conditional statements.

## Dataset

Dataset: SQL Sales Dataset – 200 Rows

The dataset contains sales-related information such as:

* Order ID
* Customer Name
* Order Date
* Category
* Sub-Category
* Product Name
* Quantity
* Unit Price
* Total Price
* Region

## Tasks Completed

* Data exploration using SELECT statements
* Filtering data using WHERE
* Grouping data using GROUP BY
* Sorting results using ORDER BY
* Total sales calculation using SUM
* Average order value using AVG
* Order and customer counting using COUNT
* Top customer analysis
* Average order value analysis
* Category-wise sales analysis
* Region-wise sales analysis
* Product-wise sales analysis
* Monthly sales analysis
* Subquery-based analysis
* CASE statement for sales classification
* JOIN-based data analysis

## Tools Used

* MySQL
* SQL
* MySQL Workbench / SQL Environment
* Excel Dataset
* GitHub

## SQL Concepts Used

| SQL Concept | Purpose                       |
| ----------- | ----------------------------- |
| SELECT      | Retrieve data                 |
| WHERE       | Filter records                |
| GROUP BY    | Group records                 |
| ORDER BY    | Sort results                  |
| SUM()       | Calculate total sales         |
| AVG()       | Calculate average values      |
| COUNT()     | Count records                 |
| JOIN        | Combine related data          |
| Subquery    | Perform nested analysis       |
| CASE        | Create conditional categories |
